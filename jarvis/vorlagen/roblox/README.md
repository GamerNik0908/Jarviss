# {{TITEL}}

Ein Roblox-Spiel, an dem Jarvis mit seinem KI-Team arbeitet. Der Code liegt hier als Dateien (Luau) und wird
mit **Rojo** nach Roblox Studio übertragen. Was das Team gemacht hat, steht in `FORTSCHRITT.md`.

## Einmal einrichten

1. **Werkzeuge:** Sag „Jarvis, richte die Roblox-Werkzeuge ein“. Jarvis installiert Rokit (falls nötig) und damit
   Rojo, Selene und StyLua sowie das Rojo-Plugin für Roblox Studio.
2. **Roblox Studio** öffnen, eine Vorlage wählen (z. B. „Baseplate“) und speichern.
3. Sag „Jarvis, starte den Live-Abgleich mit Studio“. In Studio im Tab **Plugins** → **Rojo** → **Connect**.
   Ab jetzt landet jede Änderung des Teams sofort in Studio.
4. Optional, aber empfohlen: In Studio **Assistant** öffnen → **…** → **Manage MCP Servers** →
   **Enable Studio as MCP server** einschalten. Dann kann Claude Code direkt in Studio Playtests machen, die
   Ausgabe lesen und mit der Roblox-KI 3D-Modelle und Materialien erzeugen.

## Mit Jarvis arbeiten

- „Jarvis, neue Aufgabe fürs Spiel: Baue einen Shop, in dem man Skins mit Münzen kauft.“
- „Jarvis, wie weit ist mein Spiel?“ – „Was hast du heute Nacht gemacht?“
- „Jarvis, pausiere das Spiel“ / „mach weiter“ / „plane selbst weiter“.

Veröffentlichen (Datei → In Roblox veröffentlichen) machst du selbst in Studio.
